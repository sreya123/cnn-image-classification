 Vegetable Image Classification Using CNN
 Project Overview
   This project focuses on classifying vegetable images using a Convolutional Neural Network (CNN) built with PyTorch.
   The model learns visual features from vegetable images and predicts the corresponding vegetable category.
   The project demonstrates the practical implementation of deep learning techniques for image classification.

Project Objectives
    Build an image classification model using CNN.
    Understand image preprocessing and augmentation.
    Extract image features using convolutional layers.
    Apply max pooling to reduce feature dimensions.
    Train and evaluate a deep learning model.
    Predict vegetable categories from input images.

Technologies Used
    Python
    PyTorch
    Torchvision
    NumPy
    Matplotlib
    Jupyter Notebook
Dataset
    The project uses a Vegetable Image Dataset containing 15 vegetable categories.
    The dataset is organized into three folders:
    Training
    Testing
    Validation
    Dataset source: [https://www.kaggle.com/datasets/misrakahmed/vegetable-image-dataset]
